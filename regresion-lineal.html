∑Explorador de modelos de regresión

Compara modelos a partir de tus datos

Carga una tabla, define Y y selecciona predictores X. La aplicación compara combinaciones de interacciones por pares y presenta sus métricas.

1. Carga el archivo

Excel (.xlsx, .xls), CSV o texto delimitado (.txt), con encabezados en la primera fila.

Arrastra el archivo aquío selecciónalo desde tu equipo
El archivo se procesa en tu navegador. No se envía a un servidor.

2. Selecciona variables

Y debe ser numérica. Los predictores pueden ser numéricos o categóricos.
Cada modelo contiene los efectos principales seleccionados y una combinación distinta de interacciones por pares. Las categorías se codifican automáticamente.
Se requiere al menos 3 filas completas.

3. Resultados

Modelo (efectos principales + interacciones)MAEMSER²Observaciones

Las métricas se calculan sobre las mismas filas usadas para ajustar cada modelo (ajuste dentro de muestra), no son una validación fuera de muestra. MAE = error absoluto medio; MSE = error cuadrático medio.
